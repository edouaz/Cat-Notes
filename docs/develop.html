Install the prototype

Version 0.1.0, build 8 · iOS/iPadOS 16+ · arm64 · unsigned.

Download the IPA ↓

The download is a development artifact, not a one-tap installer. iOS requires valid signing and provisioning. It is not an App Store or TestFlight release.

  1. Download the IPA to your Mac or PC.
  2. Use your own trusted signing/provisioning tool and Apple development identity to sign the app and its embedded share extension.
  3. Configure matching bundle identifiers and App Group entitlements for both targets. The default group is group.fr.catnotes.app.
  4. Install using your chosen tool. If requested by iOS, enable Developer Mode and trust your development identity.

Provisioning duration and device eligibility depend on your Apple account and signing method. See Apple’s device distribution guide. Installation after re-signing this IPA has not been tested. Building from source with Xcode is the clearest route if signing the artifact fails.

Before you try it

This is an early prototype. Export native backups before upgrading. Keep the same identifiers, team and App Group to preserve access to existing data. Do not uninstall the previous app before backing up. Pencil behavior, older hardware and accessibility still need validation.

Build from source

You need macOS and Xcode with an installed iOS simulator runtime. The deployment target is iOS 16; this does not mean the test suite has run on iOS 16. No external packages or cloud keys are needed.

git clone https://github.com/edouaz/Cat-Notes.git
cd Cat-Notes
open CatNotes.xcodeproj

Select the CatNotes scheme and an iPhone or iPad simulator, then press Run.

Use a physical device

Select your team under Signing & Capabilities for CatNotes and CatNotesShare. Use identifiers your team can provision, update the matching App Group in both Config/App.entitlements and Config/Share.entitlements, and configure that group for both targets. If changing identifiers, update Shared/ShareInbox.swift as well.

Keep project changes reproducible

The generated Xcode project is checked in. Python 3 is needed only when regenerating it after adding or removing Swift files. Make persistent build-setting changes in scripts/generate-project.py, then regenerate. If you changed the App Group, keep the generator and source configuration aligned.

python3 scripts/generate-project.py

Command-line build

xcodebuild -project CatNotes.xcodeproj -scheme CatNotes \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build

If command-line tools are selected instead of Xcode, prefix commands with DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer, adjusting the path to your installation.

Run the checks

List available destinations, then choose one installed on your machine:

xcodebuild -project CatNotes.xcodeproj -scheme CatNotes -showdestinations

xcodebuild -project CatNotes.xcodeproj -scheme CatNotes \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' \
  -derivedDataPath build -only-testing:CatNotesTests \
  CODE_SIGNING_ALLOWED=NO test

Remove -only-testing:CatNotesTests to include UI tests, or target a specific UI test class. GitHub Actions runs the unit suite on an available iPad simulator. UI tests use synthetic notebooks and may modify the simulator library; use a dedicated simulator.

Package an unsigned device build

xcodebuild -project CatNotes.xcodeproj -scheme CatNotes \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath build/CatNotes.xcarchive CODE_SIGNING_ALLOWED=NO archive

python3 scripts/package-ipa.py \
  build/CatNotes.xcarchive/Products/Applications/CatNotes.app \
  build/CatNotes-unsigned.ipa

The packaging script refuses to overwrite an existing output and verifies ZIP integrity. Unsigned packaging does not establish installability.
