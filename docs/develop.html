Install the prototype

Version 0.1.0, build 9 · iOS/iPadOS 16+ · arm64 · unsigned.

Download the IPA

The download is a development artifact, not a one-tap installer. iOS requires valid signing and provisioning. This is not an App Store or TestFlight release.

  1. Download the IPA to your Mac or PC.
  2. Use your own trusted signing/provisioning tool and Apple development identity to sign the app and its embedded share extension.
  3. Configure matching bundle identifiers and App Group entitlements for both targets. The existing group is group.fr.catnotes.app.
  4. Install using your chosen tool. If requested by iOS, enable Developer Mode and trust your development identity.

Provisioning duration and device eligibility depend on your Apple account and signing method. See Apple’s device distribution guide. Installation after re-signing this IPA has not been tested. Building from source with Xcode is the clearest route if signing the artifact fails.

Updating an existing installation

OpenNotes keeps the earlier app’s bundle identifiers, App Group, Keychain service and local data directory. These technical identifiers deliberately retain their old spelling so an in-place update can access existing notes. The app, project, modules and public identity are OpenNotes.

Export native backups first. Sign with the same team, bundle identifiers and App Group as your existing installation, and install over it. Do not uninstall before backing up. A changed signing identity or identifier may prevent access to the previous app’s data.

This is an early prototype. Physical Pencil behavior, older hardware and accessibility still need validation. Keep another copy of valuable notes.

Build from source

You need macOS and Xcode with an installed iOS simulator runtime. The deployment target is iOS 16; this does not establish runtime validation on iOS 16. No external packages or cloud keys are needed.

git clone https://github.com/edouaz/OpenNotes.git
cd OpenNotes
open OpenNotes.xcodeproj

Select the OpenNotes scheme and an iPhone or iPad simulator, then press Run.

Use a physical device

Select your team under Signing & Capabilities for OpenNotes and OpenNotesShare. Use identifiers your team can provision. Configure the same App Group for both targets in Config/App.entitlements, Config/Share.entitlements and your developer account. If changing the group, update Shared/ShareInbox.swift too. Retain the existing identifiers when upgrading an installation that contains notes.

Keep project changes reproducible

The generated Xcode project is checked in. Python 3 is needed when regenerating after adding or removing source files. Make persistent build-setting changes in scripts/generate-project.py, then regenerate:

python3 scripts/generate-project.py

Command-line build

xcodebuild -project OpenNotes.xcodeproj -scheme OpenNotes \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build

If command-line tools are selected instead of Xcode, prefix commands with DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer, adjusting the path to your installation.

Run the checks

List available destinations, then choose one installed on your machine:

xcodebuild -project OpenNotes.xcodeproj -scheme OpenNotes -showdestinations

xcodebuild -project OpenNotes.xcodeproj -scheme OpenNotes \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' \
  -derivedDataPath build -only-testing:OpenNotesTests \
  CODE_SIGNING_ALLOWED=NO test

Remove -only-testing:OpenNotesTests to include UI tests, or target a specific UI test class. GitHub Actions runs the unit suite on an available iPad simulator. UI tests use synthetic notebooks and may modify the simulator library; use a dedicated simulator.

The website appearance control has a dependency-free regression check:

node docs/tests/theme.test.cjs

Package an unsigned device build

xcodebuild -project OpenNotes.xcodeproj -scheme OpenNotes \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath build/OpenNotes.xcarchive CODE_SIGNING_ALLOWED=NO archive

python3 scripts/package-ipa.py \
  build/OpenNotes.xcarchive/Products/Applications/OpenNotes.app \
  build/OpenNotes-ios16-build9-unsigned.ipa

The packaging script refuses to overwrite an existing output and verifies ZIP integrity. Unsigned packaging does not establish installability.

Find the right starting point

  • Architecture and storage — modules, save behavior, backups and import/export.
  • Contributing — focused changes, tests and pull requests.
  • Release notes — build 9 changes, limits and artifact manifest.
  • Optional Supabase experiment — setup and validation boundaries. Not required for local notebooks.
  • Security reporting and third-party notices.

Edit this website

The site is plain HTML, CSS and a small appearance script in docs/. Preview with python3 -m http.server 8000 --directory docs. GitHub Pages publishes that directory from main. No frontend build tool, package installation or tracking script. GitHub’s publishing guide explains the Pages configuration.
